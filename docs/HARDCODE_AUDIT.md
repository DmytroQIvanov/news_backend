# Hardcode and temporary-solution audit

Audit date: 2026-11-18. Scope: backend `src/`, Python `knowledge/kb/`, mobile `App.tsx`, `api.ts`, `src/`, supporting tests and migration history. Local source was scanned for static registries, seed/fallback paths, freshness timestamps, placeholder URLs, debug output, disabled paths and exact TODO/FIXME/HACK markers. `.env` files, credentials, dependency trees, build output and unrelated `.claude` worktrees were excluded. No remote verification was performed.

## Corrected findings

| Finding / files | Change and regression coverage |

Mobile adds routes and a home navigation link. `tests/encyclopedia.test.mjs` covers citations, status, categories, grounding, evidence hashes, independence loss, lease and pagination/search. | `src/catalog/catalog.service.ts` marked skipped/failed model checks verified | Remove those timestamp writes. Empty official evidence skips verification. A successful unchanged evidence comparison may still advance freshness because the evidence was actually rechecked. Tests cover missing credentials and bundled stale data. |

## Validation and limits

Regression checks are offline. PostgreSQL-dependent integration tests need an explicit `KB_TEST_DATABASE_URL` and were not enabled; migration/application plans, real model quality, official portal correctness, physical-device navigation and new live data were not verified. Applying the new migration is an operational follow-up, not something this offline task executed.

Mobile had extensive uncommitted changes before this work. Changes here add new files and only append API/i18n entries or make small navigation/provenance/date insertions. Full Expo lint reports 52 errors and 26 warnings in existing screens/components; the new files pass targeted lint. Those existing files were not rewritten to satisfy lint. Matching Expo 58 online documentation was not fetched because the user's no-network instruction takes precedence; implementation follows existing installed Router/React Native patterns and local type definitions.

Validated locally: backend `npm test` passed 177 tests, with 7 opt-in PostgreSQL tests skipped (184 total); backend and mobile `npx tsc --noEmit` passed; mobile `npm test` passed all 34 tests; Python metadata unit tests passed all 3 tests. The broader Python runtime suite was not executed because this local interpreter lacks application dependencies (including PyYAML), and no dependencies were fetched.
